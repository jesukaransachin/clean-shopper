Design System

Reference styleguide for Clean Shopper — inspired by myntra.com's structural patterns (color-blocking, pill badges, uppercase nav), reinterpreted for a trust-first, conversational product.

Logo

Monogram "C" with a sprout leaf tucked into the opening — reads as both a brand initial and a nod to "clean/natural." Gradient runs brand green to amber, matching the palette below.
